# 权限中心原型网站发布目录

本目录包含静态原型及其所需的嵌入页面和 JSZip 依赖。仅发布此目录，不包含 PRD、Excel 模板或预览图片。

## GitHub Pages 发布

1. 在 GitHub 创建一个空的 **Public** 仓库。
2. 将本目录中的所有文件上传到仓库根目录。
3. 在仓库 Settings → Pages 中选择从 `main` 分支的 `/(root)` 发布。
4. GitHub Pages 完成发布后，分享页面显示的 `https://<用户名>.github.io/<仓库名>/` 链接。

此原型为纯静态演示页面，操作数据保存在浏览器会话中，不连接业务后端。
